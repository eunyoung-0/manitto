# 🎁 우리들의 마니또

친구들이 로그인 없이 링크만으로 참여하는 마니또 웹앱이에요.
GitHub Pages(무료 호스팅)와 Firebase(무료 DB)를 사용해요.

## 기능
- 🎲 **뽑기**: 자기 자신이나 서로를 뽑지 않도록 한 바퀴로 이어지게 뽑아요. 뽑은 사람도 결과를 못 봐요.
- 💰 **예산 & 📅 일정**: 최소/최대 예산, 선물 발송 마감일, 공개일과 시각, 메모를 정할 수 있어요.
- 💌 **익명 쪽지**: 선물하는 사람(천사)만 내 마니또에게 이름 없이 쪽지를 보낼 수 있어요. 받는 사람은 읽기만 해요.
- 🕵️ **추리 게임**: 나를 챙기는 천사가 누군지 추리해요.
- 🎉 **공개의 날**: 날짜와 시각(예: 저녁 7시 반 모임)을 정하면 카운트다운이 끝날 때 자동으로 공개돼요. 뽑은 뒤에도 공개 시각을 바꿀 수 있어요. 각자 PIN을 입력하는 순서대로 짝이 밝혀지고 명탐정이 발표돼요.
- 🔒 뽑기 결과와 쪽지는 각자의 PIN으로만 열리게 암호화해서 저장해요.

---

## 설정하기 (처음 한 번, 약 15분)

### 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 로그인해요.
2. **프로젝트 만들기**를 누르고 이름을 정해요 (예: `manitto`). Google 애널리틱스는 꺼도 돼요.
3. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**를 눌러요.
   - 위치는 `asia-northeast3 (서울)`로 해요.
   - **프로덕션 모드**로 시작해요.
4. Firestore 화면 위쪽 **규칙** 탭에서 내용을 모두 지우고 `firestore.rules` 파일 내용을 붙여 넣은 뒤 **게시**해요.
5. 프로젝트 개요 옆 ⚙️ **프로젝트 설정 → 일반 → 내 앱**에서 웹 아이콘 `</>`을 눌러 앱을 등록해요. (Hosting 체크는 안 해도 돼요.)
6. 화면에 나오는 `firebaseConfig = { ... }` 값을 복사해서 `config.js`에 붙여 넣어요.

> config.js 값은 공개되어도 괜찮은 값이에요. 접근은 규칙(firestore.rules)으로 막아요.

### 2. GitHub에 올리기
1. https://github.com 에서 **New repository**를 눌러 저장소를 만들어요 (예: `manitto`, Public).
2. **uploading an existing file**을 눌러 `index.html`, `config.js`, `firestore.rules`, `README.md`를 끌어다 놓고 **Commit changes**를 눌러요.
3. 저장소의 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)`로 정하고 **Save**해요.
4. 1~2분 뒤 `https://<내아이디>.github.io/manitto/` 주소가 생겨요.

### 3. 사용하기
1. 위 주소를 열고 **방 만들기**를 눌러요. 주소 뒤에 `#abc123` 같은 방 코드가 붙어요.
2. 예산과 일정을 정하고, **친구 초대 링크**를 단톡방에 공유해요.
3. 모두 참여하면 아무나 **뽑기**를 눌러요.
4. 각자 이름과 PIN으로 결과를 열고 쪽지를 주고받아요.

방장 권한(참여자 빼기, 처음부터 다시 하기)은 **방을 만든 기기의 브라우저**에만 저장돼요.

## 알아두면 좋은 점
- **PIN을 잊어버리면** 결과와 쪽지를 다시 열 수 없어요. 그때는 방장이 "처음부터 다시 하기"로 새로 뽑아야 해요.
- 4자리 PIN은 마음먹고 계산하면 풀 수 있어요. 친구끼리 믿고 하는 수준의 보안이에요. 더 안전하게 하려면 6자리 이상을 쓰세요.
- 방 코드를 아는 사람만 들어올 수 있으니 초대 링크는 친구들에게만 공유하세요.
- Firebase 무료 요금제(Spark)로 충분해요. 결제 정보를 등록할 필요가 없어요.
